# Climbing - chonqin 的个人博客

这是 chonqin 的个人技术博客，记录学习和生活中的点滴。

## 📝 博客简介

**Climbing** 是一个基于 GitHub Pages 托管的静态博客网站，主要分享关于 ROS（机器人操作系统）、嵌入式开发、电子竞赛等方面的学习笔记和技术心得。

- **博客名称**：Climbing
- **作者**：chonqin
- **网站地址**：[https://chonqin.github.io](https://chonqin.github.io)
- **标语**：Hello World!

## 🎯 博客主题

博客主要涵盖以下技术领域：

- **ROS（机器人操作系统）**：ROS 基础教程、机械臂控制、Raspberry Pi 应用
- **嵌入式开发**：STM32 开发相关内容
- **Linux 系统**：Linux 系统使用和开发
- **电子竞赛**：电赛经验分享
- **碎碎念**：生活感悟和心情记录

## 🛠️ 技术栈

- 静态网站生成：使用博客框架生成
- 托管平台：GitHub Pages
- 样式主题：自定义主题配置
- 前端框架：HTML5 + CSS3 + JavaScript
- 字体图标：Font Awesome
- 搜索功能：基于 JSON 的本地搜索

## 🚀 本地预览

由于这是一个静态网站项目，可以通过以下方式在本地预览：

1. 克隆仓库：
```bash
git clone https://github.com/chonqin/chonqin.github.io.git
```

2. 使用本地服务器运行：
```bash
cd chonqin.github.io
python -m http.server 8000
```

3. 在浏览器中访问：
```
http://localhost:8000
```
